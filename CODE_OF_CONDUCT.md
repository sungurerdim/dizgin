# Code of Conduct

This project follows the **Contributor Covenant, version 2.1**, which
applies to all project spaces (issues, pull requests, discussions, and
any other communication channel maintained by the project).

The full text is available at:

> <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

## Reporting

If you observe behaviour that violates the Contributor Covenant — in
this repository, in a related discussion, or in any project space —
